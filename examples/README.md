# Examples

- `basic.rs` — encode a surface.
- `decode.rs` — decode an update.
- `telemetry.rs` — collect encode phase timings.
- `parts.rs` — split an update into parts.
- `scene.rs` — use reference scenes.
- `convert.rs` — RGBA to cells and back.
- `detect.rs` — dirty tiles.
- `ops.rs` — deflate ops.
- `format.rs` — constants.
- `reference.rs` — surface of cells.
- `frame.rs` — captured frame.
- `reset.rs` — band-parallel self-contained update.
- `error.rs` — handle codec errors.

Run with `cargo run --example <name>`.
